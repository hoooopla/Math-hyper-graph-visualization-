# Proof Atlas

A private, client-side viewer for mathematical solution hypergraphs expressed as YAML.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run check
```

Phase 1 supports YAML upload and drag-and-drop, schema/reference validation, explicit AND-hyperedge rendering, node and inference inspection, theorem and mistake details, filters, search, path highlighting, zoom/pan, KaTeX, and responsive dark-mode layout.
